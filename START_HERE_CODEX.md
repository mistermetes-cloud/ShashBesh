## Цель
Создать воспроизводимую цифровую игру для 2–4 игроков и платформу AI-vs-AI / человек-vs-AI с детерминированным ядром, честными кубиками, полной историей действий, тестами и удобным веб-интерфейсом. Название: **Шашбеш AI / ShashBesh AI**; жанр: пошаговая стратегическая настольная игра с элементами случайности.

1. Проанализируй репозиторий, выдай короткий план и определи подходящий стек; если проекта нет — создай минимальный TypeScript-монорепозиторий: `packages/engine` (чистая логика), `apps/web` (React + Vite), `packages/agents` (боты), `packages/tournament` (CLI), `packages/shared` (типы). 2. Импортируй CSV; напиши тесты геометрии, затем чистый игровой движок, легальные действия и проверку максимальной суммы использованных очков.

7. Запусти тесты, сборку и несколько симуляций до победы; запиши результаты, обнови `PROJECT_STATE.md`, выдай точные команды запуска.

- Не публикуй и не деплой без разрешения. Не делай git commit без разрешения.
- Не меняй согласованные правила ради упрощения. Если неоднозначность блокирует конкретный сценарий, документируй её, изолируй через `RulePolicy`/явный режим и сообщи пользователю; не подменяй молча.
