# Проверка 1053 автоматических партий — 09.10.2026

Проведены 1053 партии с seed `validation-v2-0`…`validation-v2-1052`. Полный перебор 117 упорядоченных составов: 9 для двух игроков, 27 для трёх и 81 для четырёх. Каждый состав проверен ровно 9 раз; входят одинаковые агенты (self-play) и все смешанные сочетания random/greedy/tactical. Число участий каждой стратегии одинаково: 1269.

Первые 1000 партий сохранены отдельно; ещё 53 дополняют цикл до полностью сбалансированной серии. Добавление метаданных журнала не меняет выбор ходов и RNG: контрольные seed для 2/3/4 игроков восстановили прежние state hash.

## Диагностика

Незавершённых партий: 0. Причин незавершения нет. Подозрительных партий по установленным критериям: 0. Критерии: лимит 5000 бросков, ошибка движка/агента, неуспешный replay, более 1000 бросков или 100 подряд бросков без использованных очков. Эти пороги — диагностические, не игровые правила.

Проверен отдельный прогон с лимитом 1: три партии честно завершились статусом timeout, без победителя. Сохранены JSONL и sidecar с seed, составом, причиной и state hash в `artifacts/diagnostic-test/suspicious/`. Проверена репродукция одного такого случая с совпадением state hash; CLI вернул диагностический код 2. Проверен также отказ агента через тестовую инъекцию: ошибка записана, победитель не назначен.

```bash
# Точные seed и составы перечислены в results.json.
npm run reproduce -- --metadata artifacts/diagnostic-test/suspicious/game-0.json --output artifacts/diagnostic-test/reproduced.jsonl
```

Каждые 25 партий пишется checkpoint результатов. Все подозрительные партии записываются вместе с диагностикой и seed; при незавершении CLI возвращает код 2. Для воспроизведения исходного журнала с исходными timestamps импортировать сохранённый JSONL; повторная симуляция по seed воспроизводит поле/state hash, а время нового запуска и хеш нового журнала могут отличаться.
