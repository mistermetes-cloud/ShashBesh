# Приёмка Ubuntu ↔ Android v0.3

Программные проверки не заменяют этот протокол на физических устройствах. Оба устройства должны находиться в одной Wi-Fi сети с разрешённым обменом между клиентами. Интернет для игры не требуется.

## Установка и автономная игра

1. Установить `android/app/build/outputs/apk/debug/app-debug.apk` вручную либо `adb install -r PATH_TO_APK`.
2. Отключить интернет, оставить Wi-Fi. Запустить приложение, выбрать человека и AI v0.1, начать игру.
3. Проверить поле, пять фишек, броски, историю и отмену. Повернуть телефон, закрыть/открыть приложение; сверить позиции и журнал.

## Авторитетный узел Ubuntu

1. На Ubuntu выполнить `npm run lan:dev`, записать показанный адрес `http://IP:8787`.
2. Создать комнату в Ubuntu. На Android ввести адрес узла, нажать «Комнаты узла», подключиться.
3. Создатель начинает партию. Проверить одинаковые кубики/фишки/очередь на обоих экранах, невозможность ходить за другого игрока.
4. Повторить, создавая комнату с Android на Ubuntu-узле.

## Авторитетный узел Android

1. На Android нажать «Разместить узел на Android». Записать показанный «Адрес для Ubuntu».
2. Оставить локальный адрес `http://127.0.0.1:8787`, создать комнату на телефоне.
3. На Ubuntu открыть показанный адрес телефона либо ввести его в панели LAN. Найти комнату и подключиться.
4. Начать партию с телефона; проверить одинаковые кубики, доступность действий только текущему игроку, историю и отмену.
5. Держать приложение телефона открытым и экран включённым: узел работает в процессе приложения, постоянный фоновый сервис не реализован.

## Разрыв, восстановление и обнаружение

1. Отключить Wi-Fi клиента, выполнить разрешённый ход на узле, включить Wi-Fi. Проверить возвращение на прежнее место и одинаковый журнал.
2. Перезагрузить страницу Ubuntu, затем приложение Android. Android автоматически поднимает ранее включённый узел и восстанавливает комнаты; клиенты повторно подключаются по прежним токенам.
3. Проверить Android «Найти в Wi-Fi» для Ubuntu и второго Android. Проверить резервное подключение по IP при отсутствии multicast.
4. Повторить для 3–4 игроков и дополнительных бросков при дублях/5–6. Сохранить JSONL на устройствах, проверить replay/hash CLI.

В отчёт устройства записать модель, Android/WebView версии, тип маршрутизатора, результат каждого шага, идентификатор комнаты/партии, последний hash и файлы журналов. Приватные токены подключений не публиковать.
