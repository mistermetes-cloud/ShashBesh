# Явные рабочие трактовки v1

Правила RULES_V1.md не изменены. Ниже политики MVP из EDGE_CASES.md; это не новые согласованные правила.

- Q1/Q4 `jumpEntry: skip`: прыжок проходит сразу на следующий угол, +12 outerSteps; пересечённый вход не переводит в дом. Обычный ход при следующем достижении входа переводит в дом.
- Q2 `victory: atomic`: пятая завершённая фишка немедленно завершает игру, поэтому возможность её последующего сбития не возникает.
- Q5/Q7 `homeFreeze: contiguous-tail`: фиксация только непрерывного хвоста от Д*.5. После действия проверяем хвост, включая ранее вошедшие подвижные фишки. Автофиксация уже стоящей фишки при замыкании хвоста — рабочая трактовка, требующая подтверждения.
- Q6 `cornerPriority: per-unit`: непосредственно перед каждым действием 1 проверяются прыжки. Порядок разных номиналов выбирается свободно, затем максимизируется сумма среди допустимых последовательностей.
- Q3, Q8, Q9 реализуются непосредственно по правилам и уточнениям EDGE_CASES.

Политика и версия правил сохраняются в первом событии каждой партии. Неизвестные значения политики отклоняются.
