# SHASHBESH MOBILE — интерфейс настольной игры, 10.10.2026

## Результат

Мобильный основной экран показывает выбор места игры и соперников; в партии — физическое поле, фишки и два центральных кубика. Технические возможности сохранены в отдельном режиме через меню. Новый debug APK собран отдельно, предыдущая рабочая сборка не перезаписана. Визуальное согласование пользователем ещё не получено: скриншоты подготовлены для просмотра.

## Изменения

- Главная: «На этом устройстве» / «По Wi-Fi», «С компьютером» / «С человеком», 2–4 участника. Обычный компьютер — Tactical; не заявляется новое улучшение стратегии. Wi-Fi сейчас только для людей, выбор компьютера там явно отключён. Продолжение сохранённой партии — отдельная кнопка, без сброса состояния.
- Поле: деревянная фактура CSS, светлые клетки, объёмные цветные фишки без номеров. 48 внешних +16 внутренних физических клеток CSV; каждый из четырёх домов имеет 5 позиций, общая стартовая клетка включена в маршрут. Все координаты и правила неизменны. Резервные фишки лежат в пустых углах доски, не являются дополнительными игровыми клетками.
- Два кубика находятся в пустой центральной области. SVG точки показывают реальные значения из журнала, до первого броска грани пустые; предыдущий результат не превращается в 1–1. Использованные и доступные кубики отличаются, дубль/повторный бросок отмечены. При отсутствии оставшихся ходов касание кубиков завершает бросок; новый фактический бросок требует следующего касания. Это сохраняет окно отмены перед передачей очереди.
- Сначала выбирается фишка, затем подсвеченная допустимая клетка. Маска берётся только у существующего Engine; действия выбранной фишки фильтруются без расширения легальных ходов. Неоднозначные действия требуют выбора. Компьютер автоматически ходит в обычном режиме; чужой ход Wi-Fi блокирует локальные действия.
- Активный домашний маршрут подсвечен, текущий цвет показан небольшим маркером. Все пять фишек каждого участника присутствуют в резерве/на поле/в доме; видны 2–4 реальных комплекта.
- «Отменить» доступно человеку в рамках существующего незавершённого хода. История открывается через меню: предыдущие позиции, до/после, выделение источника/цели. Просмотр не изменяет live игру. Для списка записей доступны все прежние метаданные.
- IndexedDB повышен с версии1 до2 с сохранением old saves. При начале другой локальной партии прежняя помещается в архив, не удаляется. «Сохранённые партии» открывает её через проверенный replay и восстанавливает RNG. Текущая и архивная копии одного game ID не дублируются в списке.
- Скрытый технический режим сохраняет Random/Greedy/Tactical/AI v0.1, наблюдение, историю, журнал, данные обучения, checkpoint, экспорт/импорт, seed и диагностику. Рабочая Ubuntu версия доступна там; существующие функции не удалены.
- Wi-Fi: «Создать игру» → «Найти игру» → «Присоединиться». Android создаёт игру через прежний native host; браузер использует реально доступный узел. Без него создание отключено, а не имитируется. Названия моделей/протоколов/IP отсутствуют в основном потоке; ручной адрес и команды находятся в дополнительных настройках. Автоматическое NSD обнаружение требует настоящего Android/Wi-Fi испытания; браузер ищет по известному адресу и discovery relay. Код комнаты как самостоятельный механизм не реализован и не показан готовым.

SHA256 проверка подтвердила неизменность 14 файлов Engine/shared, моделей, RULES_V1.md и CSV. Git diff для packages/engine/shared/agents/neural, правил и CSV пуст. Правила/геометрия/нейросеть не переписывались.
