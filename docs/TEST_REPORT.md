## Известные ограничения

Q1/Q2/Q4/Q5/Q6/Q7 реализованы как явные рабочие политики из OPEN_RULE_QUESTIONS.md, не как новые утверждённые правила. Боты базовые, без обучения. Турниры доступны через CLI. Автоматического сохранения и продолжения импортированной партии нет: импорт служит просмотру, текущая партия сохраняется для возврата. Журнал содержит всю историю; UI показывает последние 100 событий. Сетевая игра и деплой не входят в реализацию. Для долговременного хранения экспортируйте JSONL.
